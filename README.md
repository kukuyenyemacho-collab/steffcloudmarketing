# Steff Cloud — Digital Marketing Website

Public marketing site for **STEFF CLOUD LIMITED**'s digital marketing practice (Nakuru, Kenya, serving clients worldwide).
Static HTML generated by a small Node build: no framework, no tracking without consent, fast on 3G.

## What's inside (36 pages)
- **Home**: top CTA bar, hero lead form, services, process, comparison table, GEO section, global clients, pricing, FAQ, blog teaser
- **8 service pages** (`/services/...`), **Pricing** with a **growth calculator** and currency switcher (KES / USD / EUR / GBP)
- **Nakuru** landing page, **International** (Kenya market entry) page, **Free audit**, **About**, **Contact** (open-now status, copy buttons), **FAQ**
- **Learn**: 10 blog guides, 44-term glossary, RSS feed
- **Legal**: Privacy Policy (Kenya DPA 2019 + EU/UK GDPR), Terms, Cookie Policy, Refund Policy, Disclaimer, Accessibility Statement, Legal Notice

## Built-in systems
| Area | What it does |
|---|---|
| Leads | Every form validates Kenyan and international numbers, then opens a pre-filled WhatsApp chat to +254 118 407 026. Optional email copy via `formEndpoint`. Spam honeypot + timing trap. |
| Cookies | Banner with Accept all / Reject all / Customise, preferences dialog, “Cookie settings” in the footer, Google Consent Mode v2, Global Privacy Control respected. GA4 and Meta Pixel load only after consent. |
| Security | Strict Content-Security-Policy (no inline scripts except one hashed theme line), HSTS, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy, COOP/CORP, `/.well-known/security.txt`. Generated for Netlify/Cloudflare (`_headers`), Vercel (`vercel.json`) and cPanel/Apache (`.htaccess`). |
| Speed | Self-hosted variable fonts (no Google Fonts request, also better for GDPR), WebP logos, minified CSS/JS with cache-busting, Google Maps loads only on click. ~180 KB first load. |
| SEO / GEO | Per-page titles, descriptions, canonicals, hreflang, Open Graph, JSON-LD (ProfessionalService, Service, FAQPage, BlogPosting, BreadcrumbList, DefinedTermSet), sitemap, robots.txt (AI crawlers allowed), `llms.txt`, RSS. |
| Experience | Light and dark themes (follows the device, with a toggle), mobile call bar, WhatsApp button, reading progress on articles, reduced-motion support, WCAG 2.2 AA. |

| File | What |
|---|---|
| `src/data.js` | Contact details, domain, prices, services, plans, FAQs, socials, GA4 / Meta Pixel IDs, form endpoint, company IDs, currency rates |
| `src/posts.js` | Blog posts |
| `src/glossary.js` | Glossary terms |
| `src/legal.js` | Legal pages |
| `src/pages-extra.js` | International page, growth calculator, global section |
| `src/assets/styles.css`, `src/assets/main.js` | Design and browser behaviour (minified into `public/` on build) |

```bash
npm install        # once
npm run build      # regenerates public/
npm run serve      # http://localhost:4173 with production security headers
npm test           # full browser stress test (see TESTING.md)
npm run test:load  # load test
npm run preview    # relative-link copy in preview/ for sub-folder hosting
```

## Before going live
1. Set `site.url` in `src/data.js` to the real domain (default `https://marketing.steffcloud.co.ke`).
2. Add social profile URLs to `site.socials`, and company numbers to `site.legalIds` (shown on the Legal Notice page).
3. Optional: add GA4 (`site.ga4`), Meta Pixel (`site.metaPixel`) and a form endpoint (`site.formEndpoint`). The CSP updates itself on rebuild.
4. Confirm prices, promises and currency rates match how you operate; have a lawyer review the legal pages.
5. Deploy, then submit `sitemap.xml` in Google Search Console and Bing Webmaster Tools, and check headers at securityheaders.com.

## Deploy
- **Netlify / Cloudflare Pages**: build `npm run build`, publish `public` (headers from `public/_headers`).
- **Vercel**: uses `vercel.json` (generated with headers).
- **cPanel / shared hosting**: run `npm run build` locally and upload the contents of `public/` (including `.htaccess` and `.well-known/`).
